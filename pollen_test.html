freeai — quick test

A minimal harness for Pollinations.AI's unified gen.pollinations.ai endpoint — the same stack behind Azad-sl/FreeAI. No key, no signup. Chat, image, and speech, straight from the browser.

Requests go directly from your browser to gen.pollinations.ai (text / image / audio routes). If a call fails, the free tier may be rate-limited or a model may be asleep — try again or switch models. No API key is sent, so some premium models may be unavailable.
